# 🌯 Controle de Lanches

Um painel web dinâmico e em tempo real desenvolvido para gerenciar rachas e pagamentos de lanches em grupo, com controle de acesso para administrador e sincronização em nuvem.

## ✈️ Tecnologias Utilizadas
* **HTML5 / CSS / JavaScript:** Interface moderna e responsiva focada em dispositivos móveis.
* **Firebase Firestore:** Banco de dados NoSQL em nuvem para sincronização de dados em tempo real.
* **GitHub Pages:** Hospedagem estática contínua.

## ✨ Funcionalidades
* **Tempo Real:** Atualizações instantâneas de status de pagamento para todos os usuários conectados.
* **Modo Administrador:** Acesso protegido por senha para gerenciar, adicionar ou remover itens da lista.
* **Cálculos Automáticos:** Indicadores visuais de custo total, valores arrecadados e valores pendentes.
